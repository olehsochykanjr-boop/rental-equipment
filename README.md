# Прокат обладнання

Веб-застосунок для обліку прокату техніки: студенти можуть подавати заявки на отримання ноутбуків, камер, датчиків та іншого обладнання, а адміністратор підтверджує видачу і приймає повернення.

## Стек технологій
- Клієнт: HTML, CSS, JavaScript
- Сервер: Node.js, Express
- База даних: SQLite

## Статус
Проєкт у розробці. Детальний опис запуску та API буде доданий на завершальному етапі.
